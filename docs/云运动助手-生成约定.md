# 云运动助手类程序 · 生成约定

> 本约定由用户在 2026-10-17 明确要求，适用于 **CHZUyyd 以及后续
> 任何同类的“云运动助手”程序**（Windows、Android 或其他平台）。
> 以后生成/修改/打包这类程序时，默认遵守以下规则，除非用户明确要求保留数据。

## 1. 不内置历史轨迹

- **不得**把真实账号抓取到的 `tasklist_N.json` 预置进程序、APK、安装包或压缩包；
- `tasks_*`（如 `tasks_BBU`、`tasks_CHZU`）目录在交付时**必须为空**，
  只允许保留 `说明.txt`；
- 首次安装/首次启动后，历史轨迹列表应为 0 条；
- 打表模式必须先由用户到「历史数据」页自行抓取至少 1 条记录才能使用；
- README、使用说明、截图、测试报告中不得声称“已内置 N 条轨迹”。

## 2. 打包前强制清理

每次构建 exe/APK/安装包/zip 前执行：

```powershell
Get-ChildItem <项目>\tasks_* -Filter "tasklist_*.json" -Recurse | Remove-Item -Force
```

并检查：

```powershell
Get-ChildItem <项目> -Recurse -Filter "tasklist_*.json"
```

确认输出为空。安装包的 payload、APK 的 `assets/`、zip 里都不得出现轨迹文件。

## 3. 删除功能是必备项

历史数据页面必须提供：

1. **单条删除**：选中/点击一条已保存轨迹 → 确认 → 删除；
2. **清空全部**：一次删除所有 `tasklist_*.json`，保留 `说明.txt`；
3. 删除前二次确认，删除后刷新列表/日志，并在无轨迹时提示先抓取；
4. 跑步任务执行中应拒绝删除，避免正在使用的轨迹被删掉。

Windows 版与 Android 版的实现：

- Windows：`gui/page_history.py` 的「删除选中」/「清空全部」；
- Android：`AppRepo.deleteTrack()` / `AppRepo.deleteAllTracks()`，
  历史页的红色删除图标 /「清空全部」按钮。

## 4. 测试数据

- 单元测试/离线测试使用**合成轨迹**（代码里临时生成，测试结束删除），
  不复制真实 `tasklist_N.json` 作为 fixture；
- 联调测试抓取的轨迹只写入临时目录，测试结束立即删除；
- 不把真实轨迹提交到源码目录、`docs/images` 或任何交付物。

## 5. 交付检查清单

- [ ] `tasks_*` 只有 `说明.txt`
- [ ] 源码树无 `tasklist_*.json`（测试临时目录除外）
- [ ] exe/APK 安装包内无轨迹
- [ ] zip 内无轨迹
- [ ] 历史页显示 0 条，并提示“请先抓取”
- [ ] 单条删除、清空全部可用
- [ ] README/使用说明与“不内置”一致

## 6. 说明

轨迹是用户账号的私有运动数据，默认不随程序分发；需要时由用户自己抓取、
自己管理、自己删除。程序只提供抓取/保存/删除能力，不预置任何人的轨迹。
