# CHZUyyd 安卓版 · 用户使用说明

> 版本 1.0.0 · 仅适用于 **滁州学院**（school_id=106）
> 支持 Android 8.0（API 26）及以上，release APK 仅含 arm64-v8a。

## 1. 安装

1. 把 `CHZUyyd-v1.0.0-arm64.apk` 传到手机（微信文件传输 / 数据线均可）；
2. 在手机文件管理器里点开 APK；
3. 若提示“禁止安装未知来源应用”，按提示允许当前文件管理器安装；
4. 安装完成后，桌面出现「云运动·滁州」图标。

> 如果手机是 32 位老机型（2018 年以前），本 APK 不支持。
> 华为鸿蒙 4 / 小米澎湃 OS 等仍按 Android 应用方式安装。

## 2. 首次启动与权限

第一次打开会请求 **通知权限**，建议允许（跑步进度和结果需要通知）。

然后到「设置」页，按顺序处理：

| 项目 | 操作 |
|---|---|
| **精确闹钟** | 点「去授权」→ 允许“闹钟和提醒” |
| **电池优化** | 点「去设置」→ 允许后台运行 / 不优化 |
| **自启动 / 后台活动** | 国产 ROM 需到系统设置里允许本应用自启动（设置页有文字指引） |

不同品牌路径参考：

- 小米：设置 → 应用设置 → 应用管理 → 云运动·滁州 → 自启动 / 省电策略 → 无限制
- 华为：设置 → 应用 → 应用启动管理 → 云运动·滁州 → 手动管理（全部允许）
- OPPO/vivo：设置 → 电池 → 后台耗电管理 → 允许后台运行

## 3. 登录

1. 打开「账号」页；
2. 填写学号、密码；
3. 点「保存账号」，再点「登录」；
4. 显示 **已登录（token：…）** 即成功。

> ⚠ 登录会让手机端云运动下线，请尽量减少重复登录。
> 本 App 只接受滁州学院账号，学校参数已固定。

## 4. 历史数据

1. 打开「历史」页；
2. 点「获取学期列表」；
3. 点选一个学期（默认当前学期），会自动加载跑步记录；
4. 点选一条记录 → 点「抓取并保存到 tasks_CHZU」；
5. 下方「已保存的轨迹」会显示条数、距离和点数；
6. **删除**：
   - 单条：点轨迹右侧的红色删除图标 → 确认；
   - 全部：点「清空全部」→ 确认（只删 `tasklist_*.json`，保留说明文件）。

本 App **不内置任何轨迹**，首次安装后列表为空，必须先抓取至少 1 条才能跑步。
如果学校路线调整，再抓取最新记录即可。

> 只接受 `schoolId=106` 的记录；其他学校记录会被拒绝保存。

## 5. 定时跑步

1. 打开「跑步」页；
2. **目标跑步次数**：填 1~N；填 0 表示不限次数；
3. **每天执行时间**：输入 `HH:MM` 后点「添加」，可添加多个；
4. **错过时间点后补跑**：建议 30 分钟；
5. **为轨迹添加漂移**：按需开启；
6. 点「保存设置」；
7. 点「开始自动执行」。

开启后「下次执行」会显示具体时间，系统闹钟已注册。
到点后 App 会启动前台服务执行跑步，通知栏显示进度。

- 需要保持手机开机、App 未被“强行停止”；
- 关机/重启后，打开一次 App 或等开机广播恢复闹钟；
- 目标次数完成后自动停止；
- 「立即执行一次（不计次数）」用于手动试跑，不计入目标次数；
- 跑步中可点「取消当前跑步」。

> **学校有允许跑步的时间段**。如果服务器提示
> “当前时间不在学校规定的跑步时间内”，请换到允许时段再跑。
> App 会把学校返回的提示原样显示在「跑步进度」卡片和日志里。

## 6. 跑步进度

跑步时「跑步进度」卡片显示：

- 进度条百分比；
- `已上传 210 / 480 个点`；
- `已用时 07:54  预计剩余 11:05`；
- 通知栏同步显示进度。

上传过程中不要强制停止 App；如果电话进来，前台服务会继续跑。

## 7. 查看日志与排查

「日志」页显示最近 600 行；完整日志在：

```
应用私有目录/files/logs/app.log
```

常见问题：

| 现象 | 处理 |
|---|---|
| 登录失败 | 检查学号/密码；确认是滁州学院账号；换网络重试 |
| 提示登录失效 | 到「账号」页重新登录 |
| 提示不在跑步时间 | 学校服务器限制，换允许时段 |
| 定时没触发 | 检查精确闹钟、电池优化、自启动；到设置页点「重排闹钟」 |
| 抓取失败 | 先获取学期列表；弱网时重试 |
| 没有轨迹 | 本 App 不内置轨迹；到「历史」页抓取一条 |

## 8. 更新与卸载

- 更新：直接安装新 APK 覆盖（签名一致）；账号和轨迹保留。
- 卸载：桌面长按图标 → 卸载；或在系统设置 → 应用 → 云运动·滁州 → 卸载。
- 卸载会删除应用私有目录里的账号、轨迹和日志。

## 9. 安全提醒

- 密码/token 只保存在应用私有目录，请不要把手机借给他人；
- 不要 Root 后把 `shared_prefs` 导出；
- 打表属于模拟数据，被人工核查有风险；请遵守学校规定，风险自负；
- 本程序仅供技术交流学习。
