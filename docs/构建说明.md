# CHZUyyd 安卓版 · 构建说明

## 1. 环境要求

| 组件 | 版本 / 路径 | 说明 |
|---|---|---|
| Windows | 10/11 | 本机 Windows 11 |
| JDK | 17 或 21 | 本机 `C:\Program Files\Java\jdk-21.0.11` |
| Android SDK | platform 35 + build-tools 35.0.0 | 本机 `C:\Android\sdk` |
| Android Gradle Plugin | 8.7.3 | `android/build.gradle.kts` |
| Gradle | 8.9 | 工程自带 wrapper |
| Kotlin / Compose | 2.0.21 / BOM 2024.12.01 | |
| Chaquopy | 17.1.0 | 支持 Python 3.14、AGP 7.3–9.4 |
| Python | 3.14 | Chaquopy `buildPython("py", "-3.14")` |
| ABI | arm64-v8a（release）/ x86_64（调试模拟器） | |

`android/local.properties` 需要指向 SDK：

```properties
sdk.dir=C\:\\Android\\sdk
```

`build_apk.bat` 会在缺失时尝试根据 `ANDROID_HOME` 生成；也可以手工创建。

## 2. 一键构建

在项目根目录双击 / 运行：

```bat
build_apk.bat
```

脚本会：

1. 定位 `JAVA_HOME`（未设置时尝试本机 JDK 路径）；
2. 定位 `ANDROID_HOME`（默认 `C:\Android\sdk`）；
3. `gradlew.bat assembleDebug`（arm64 + x86_64）；
4. `gradlew.bat assembleRelease -PchzuAbis=arm64-v8a`；
5. 复制到 `dist/`：
   - `CHZUyyd-v1.0.0-arm64.apk`
   - `CHZUyyd-v1.0.0-debug.apk`。

## 3. 手动构建

```powershell
cd android
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease "-PchzuAbis=arm64-v8a"
```

> PowerShell 里带逗号的 `-PchzuAbis=arm64-v8a,x86_64` 必须整体加引号，
> 否则会被当成数组参数。

首次构建会下载 AGP、Kotlin、Compose、Chaquopy 以及 Chaquopy 的
Python 3.14 for Android 运行时（约几百 MB），需要联网。

## 4. Chaquopy / Python 配置

`android/app/build.gradle.kts`：

```kotlin
chaquopy {
    defaultConfig {
        version = "3.14"
        if (buildPythonPath != null) buildPython(buildPythonPath)
        else buildPython("py", "-3.14")
    }
    sourceSets {
        getByName("main") {
            srcDir("../../python")
        }
    }
}
```

- Python 源码在项目根 `python/`，模块为 `proto.*`；
- 不需要 `pip install` 任何包：`proto/vendor/gmssl` 是随包的纯 Python 子集，
  HTTP 用标准库 `urllib`；
- 如果 `py -3.14` 不可用，设置环境变量：

```powershell
$env:CHZU_BUILD_PYTHON = "C:\Path\To\python.exe"
```

## 5. 签名

**仓库不包含签名私钥**：`android/keystore/` 与 `android/keystore.properties`
已被 `.gitignore` 排除。仓库内的 APK 已签名，可直接安装；如果要重新构建
release，请在本机生成自己的签名：

```properties
# android/keystore.properties
storeFile=keystore/chzuyyd-release.jks
storePassword=你的密码
keyAlias=chzuyyd
keyPassword=你的密码
```

生成 keystore：

```powershell
New-Item -ItemType Directory -Force android\keystore | Out-Null
keytool -genkeypair -v -keystore android\keystore\chzuyyd-release.jks `
  -alias chzuyyd -keyalg RSA -keysize 2048 -validity 10000 `
  -storepass 你的密码 -keypass 你的密码 `
  -dname "CN=CHZUyyd, O=CHZU, L=Chuzhou, ST=Anhui, C=CN"
```

- 私钥/密码只保存在本机，**不要提交到仓库**；
- 更换签名后，已安装的旧版本需要先卸载才能覆盖安装；
- 仓库内已签名的 APK 与源码可以同时分发；他人若要重新签名，需要自行生成密钥。

## 6. 中文路径

AGP 默认拒绝含非 ASCII 字符的工程路径。工程已在
`android/gradle.properties` 中设置：

```properties
android.overridePathCheck=true
```

并已在 `D:\yunyundong\CHZUyyd-Android` 下实测构建通过。

如果仍遇到 aapt2/Python 环境路径问题，可以创建一个 ASCII 联接点再构建：

```powershell
cmd /c mklink /J C:\chzu-android "D:\yunyundong\CHZUyyd-Android"
cd C:\chzu-android\android
.\gradlew.bat assembleRelease "-PchzuAbis=arm64-v8a"
```

## 7. 常见构建问题

| 问题 | 处理 |
|---|---|
| `JAVA_HOME is set to an invalid directory` | 指向 JDK 根目录（含 `bin\java.exe`），不是 `javapath` |
| `sdk.dir` 错误 / 找不到 android.jar | 确认 SDK platform 35 已安装，修正 `local.properties` |
| Chaquopy pip 失败 | 本工程无 pip 依赖；确认没有改动 chaquopy `pip` 块 |
| 非 ASCII 路径报错 | 确认 `android.overridePathCheck=true`，或用联接点 |
| release 未签名 | 确认 `keystore.properties` 与 jks 存在，且路径相对 `android/` |
| 首次构建很慢 | Chaquopy 下载 Python 3.14 运行时，耐心等待 |

## 8. 产物校验

```powershell
C:\Android\sdk\build-tools\35.0.0\apksigner.bat verify --print-certs `
  dist\CHZUyyd-v1.0.0-arm64.apk

C:\Android\sdk\build-tools\35.0.0\aapt.exe dump badging `
  dist\CHZUyyd-v1.0.0-arm64.apk
```

`aapt` 对中文路径可能报 `Illegal byte sequence`，把 APK 复制到纯英文路径再执行即可。
